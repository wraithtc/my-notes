## 关键技术原理详解

### 1. 双频GPS为什么准？

| 原理 | 说明 |
|------|------|
| **问题** | 电离层会使GPS信号延迟，单频无法区分延迟大小 |
| **解决** | L1(1575.42MHz)和L5(1176.45MHz)两个频率的延迟不同 |
| **计算** | 通过两个频率的到达时间差，反推电离层延迟量 |
| **效果** | 消除电离层误差(可达5-10米)，精度提升30-50% |
| **代价** | 需要双频射频前端+双通道基带处理，芯片成本增加2-3倍 |

**实际案例**：
- 单频手机：开阔环境2-5米，城市环境5-15米
- 双频手机：开阔环境1-3米，城市环境3-8米
- **精度提升**：30-50%

### 2. 圆极化天线为什么准？

| 原理 | 说明 |
|------|------|
| **问题** | 普通线极化天线与卫星圆极化信号不匹配，损失3dB信号 |
| **解决** | 圆极化天线与GPS信号极化方式完全匹配 |
| **效果** | 信号增益3-5dB，相当于信号强度提升2-3倍 |
| **场景** | 城市峡谷、树林遮挡等弱信号环境优势明显 |
| **代价** | 天线设计复杂，需要专利技术，成本增加3-5倍 |

**小天才专利**：
- 30+项圆极化天线专利
- 信号增益比普通天线高3-5dB
- 城市环境精度提升40%

### 3. WiFi定位为什么室内准？

| 原理 | 说明 |
|------|------|
| **问题** | 室内GPS信号衰减20-30dB，无法定位或精度极差(20-50米) |
| **解决** | 扫描周边WiFi路由器MAC地址，云端数据库匹配位置 |
| **数据** | 全球WiFi位置数据库(数亿个WiFi热点位置) |
| **效果** | 室内精度从20-50米提升到3-5米，**提升5-10倍** |
| **代价** | 需要WiFi芯片(¥20-40)+云端服务(持续成本) |

**实际精度**：
- 无WiFi定位：室内20-50米
- 有WiFi定位：室内3-5米
- **精度提升**：5-10倍

### 4. 气压计楼层识别原理

| 原理 | 说明 |
|------|------|
| **物理规律** | 海拔每升高1米，气压下降约0.12百帕 |
| **换算** | 每层楼(约3米)→气压变化约0.36百帕 |
| **校准** | 通过云端气压参考站实时校准，消除天气影响 |
| **效果** | 楼层识别精度±1层 |
| **限制** | 需要初始楼层校准，密闭空间气压可能不准 |

**小天才实现**：
- 楼层定位3.0算法
- 支持超高楼定位(上海中心大厦等)
- CQC五星级认证

### 5. RTK/PPP校正为什么能达到1米？

| 原理 | 说明 |
|------|------|
| **问题** | GPS误差来源：卫星轨道误差(2米)、钟差(2米)、电离层(5-10米)、对流层(1米) |
| **解决** | 地面参考站(已知精确位置)实时计算误差修正量 |
| **传输** | 通过网络/卫星广播校正数据到手机 |
| **效果** | 消除大部分误差，精度从2-5米→1米以内 |
| **代价** | 需要订阅服务($5-20/月)或一次性购买(¥500-1000) |

**Qualcomm+Trimble RTX**：
- 小米15支持RTX服务
- 全球参考站网络
- 实时校正，延迟<5秒
- 精度：1米(CEP50%)

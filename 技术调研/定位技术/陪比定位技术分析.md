# 陪比宠物定位器技术分析

## 品牌背景

陪彼（PETBIT）是深圳市陪彼宠物科技有限公司旗下品牌，专注于宠物智能设备研发。其产品是业内首批采用 **NB-IoT 物联网技术** 的宠物定位器。

**主要产品型号：**
- G1/G1S：一代产品
- G20-Pro：二代产品（约 ¥499）

---

## 定位技术架构

### 多模定位系统

陪比采用**多重定位技术融合**方案：

| 定位方式 | 用途 | 精度 |
|---------|------|------|
| **GPS** | 户外主要定位 | 5-15米（开阔地） |
| **北斗卫星** | 中国区域增强 | 5-15米 |
| **Wi-Fi 指纹定位** | 室内定位 | 10-30米 |
| **LBS 基站定位** | 信号弱时兜底 | 100-1000米 |
| **NB-IoT (5G)** | 数据传输 + 辅助定位 | - |

### 定位流程

```
卫星(GPS/北斗)获取位置 → NB-IoT网络传输 → 手机APP显示
     ↓ 信号弱时
WiFi/LBS辅助定位 → 上传服务器
```

## 超长待机 30 天的技术原理

> [!important] 核心结论
> 陪比能做到 30 天待机，**核心在于 NB-IoT 低功耗通信技术 + 智能省电算法**。

### 1. NB-IoT 低功耗机制

NB-IoT（Narrow Band IoT）是专为物联网设计的**低功耗广域网（LPWAN）技术**，具备三种工作模式：

#### PSM (Power Saving Mode) - 省电模式
- **原理**：设备空闲一段时间后进入深度睡眠，关闭射频和信令处理
- **功耗**：极低，约 **3-5μA**（微安级）
- **特点**：设备"冬眠"，无法接收下行数据，但几乎不耗电

#### eDRX (Extended DRX) - 扩展非连续接收
- **原理**：延长设备的休眠周期，减少唤醒监听网络的次数
- **寻呼周期**：可达 **40分钟~2.5小时**（传统4G仅2.56秒）
- **平衡**：在低功耗和可达性之间取得平衡

#### NB-IoT vs 4G Cat.1 工作模式功耗对比

| 工作模式 | **NB-IoT** | **4G Cat.1** | 响应能力 | 说明 |
|---------|-----------|-------------|---------|------|
| **Connected（全激活）** | ~100-150mA | ~200-500mA | 实时 | 数据传输时，Cat.1功耗高3-5倍 |
| **Idle（轻睡眠/DRX）** | ~3-5mA | ~20-30mA | 较快 | 等待唤醒，Cat.1高6-10倍 |
| **Sleep（睡眠态）** | ~0.5-1mA | ~2-3mA | 需唤醒 | Cat.1部分模组支持 |
| **PSM（深度睡眠）** | ~3-5μA | 不支持/高功耗 | 不可达 | NB-IoT核心优势 |

> [!tip] 关键差异
> - **Cat.1 空闲态功耗约 20-30mA**，是 NB-IoT 的 **6-10倍**
> - **Cat.1 大多不支持 PSM**，无法进入微安级深度睡眠
> - 这就是为什么 **4G 定位器续航仅 3-7天**，而 NB-IoT 可达 **7-30天**

**数据来源**：
- NB-IoT：行业通用数据，PSM模式 3-5μA
- 4G Cat.1：移远 EG91/EC200U 系列 Datasheet，空闲态 ~29mA

### 2. 智能省电算法

陪比宣称的**专利算法**实现：

- **运动状态感知**：识别宠物运动状态（跳跃、奔跑、走动、静止）
- **动态定位频率**：
  - 静止时：降低定位频率（如每小时一次）
  - 运动时：提高定位频率（如每5分钟一次）
- **智能唤醒**：仅在需要时唤醒GPS模块

### 3. A-GPS 辅助定位加速

**A-GPS（Assisted GPS）** 技术通过以下方式降低功耗：

```
传统GPS冷启动：搜索卫星 → 下载星历 → 计算位置（30秒~2分钟，高功耗）
A-GPS：网络下发星历 → 快速锁定卫星（1-5秒，低功耗）
```

- **原理**：将定位过程中最耗时、最耗电的星历下载"外包"给网络
- **效果**：显著缩短首次定位时间（TTFF），减少GPS模块工作时长

### 4. 硬件设计

- **电池容量**：约 500mAh（根据型号略有差异）
- **低功耗GNSS芯片**：优化卫星接收效率
- **轻量化设计**：减少持续供电负担

## 定位精度分析

### 理论精度

| 环境 | 定位方式 | 精度范围 |
|------|---------|---------|
| 开阔户外 | GPS+北斗 | **5-15米** |
| 城市街道 | GPS+北斗+WiFi | **10-50米** |
| 室内 | WiFi+LBS | **20-100米** |
| 信号盲区 | LBS基站 | **100-1000米** |

### 实测用户反馈与证据

> [!warning] 实际使用注意
> - 官方宣传 30 天待机，**实际续航因使用场景差异巨大**（5-30天不等）
> - 城市复杂环境下定位精度有所下降
> - 室内或地下等GPS信号弱区域依赖WiFi/LBS，精度较低

## 技术优势总结

### 为什么能同时做到低功耗 + 较高精度？

| 技术手段 | 解决的问题 |
|---------|-----------|
| **NB-IoT PSM/eDRX** | 通信模块低功耗待机 |
| **A-GPS辅助定位** | 缩短GPS工作时长，降低功耗 |
| **智能省电算法** | 根据运动状态动态调节功耗 |
| **多模定位融合** | GPS精度不够时用WiFi/LBS补充 |
| **北斗卫星增强** | 中国区域定位精度提升 |

### 关键技术权衡

```
低功耗 ←—————————→ 高精度
    ↑                  ↑
    └─ 智能调节策略 ──┘
```

- **牺牲**：实时性（非连续追踪，有延迟）
- **换取**：30天待机 + 5-15米精度

## 潜在问题与限制

1. **流量续费**：超过1个月不续费需支付保号费，超180天可能设备失效
2. **网络依赖**：无移动网络覆盖区域无法工作
3. **实际续航差距**：宣传30天，高频使用下实际7-10天
4. **室内精度**：依赖WiFi/LBS时精度下降明显

# 小天才手表极致小型化分析 — 对标与差距评估

> **目的**：向领导汇报为什么小天才能做到极致小型化，我们的可视定位器产品为什么存在技术差距，以及可行的技术路线。
> **日期**：2026-06-03

---

## 一、小天才为什么能做到那么小

### 1.1 核心原因：高度集成的穿戴级SoC

小天才旗舰手表（Z6/Z9/Z10系列）不是简单的硬件堆叠，其核心是一颗**高度集成的穿戴SoC**，将以下功能集成在**单颗芯片**内：

| 集成模块 | 说明 |
|---------|------|
| CPU（ARM Cortex-A系列） | 足以运行定制Android系统 |
| 4G基带（Cat.4/Cat.6） | 支持视频通话 |
| WiFi + 蓝牙 | 室内定位辅助 + 外设连接 |
| GNSS（GPS+北斗+GLONASS） | 室外精准定位 |
| ISP（图像信号处理器） | 直接驱动摄像头 |
| H.264/H.265 视频编解码 | 视频通话/拍照 |
| PMU（电源管理） | 集成电源管理单元 |

**对比传统方案**：如果用独立芯片方案，需要 SoC + 独立GPS芯片 + 独立WiFi芯片 + 独立视频编解码器 + 独立PMU = **5-6颗主芯片**，PCB面积至少大3-4倍。

**关键结论：小天才的小型化，本质上是一颗高度集成SoC带来的系统级优势，不是PCB设计技巧能弥补的。**

### 1.2 这些SoC从哪来

这些高集成穿戴SoC来源于**手机产业链的技术溢出**：

```
手机产业链演进：

2005年 → CPU/基带/GPS/WiFi 各自独立芯片
2010年 → 基带与射频开始集成
2015年 → CPU+GPU+基带+ISP+视频编解码 合为一颗SoC
2018年 → WiFi/BT/GNSS也被集成进来
现在   → 穿戴市场复用手机SoC架构，降低规格/封装 → 穿戴专用SoC
```

- **芯片商（展锐/联发科/高通）**并非专门为小天才定制芯片
- 他们将手机SoC已有的IP模块**重新组合**，封装成穿戴规格的SoC
- **卖给整个穿戴品类**：儿童手表、POS机、对讲机、健康手环……
- 小天才只是其中一个客户，但他们的**整机集成能力**（PCB布局、结构设计、软件优化）做得最好

### 1.3 小天才的其他小型化手段

除了SoC集成，小天才在整机层面还做了：

| 手段 | 具体做法 |
|------|---------|
| PCB叠板设计 | 主板+副板通过FPC连接，围绕电池排布 |
| 电池藏入表带 | 电池不在表盘内，用柔性/长条电池穿入表带 |
| LDS天线 | 激光直接成型在塑料壳体上，省去天线空间 |
| 0402/0201器件 | 电阻电容用超小封装 |
| 屏蔽罩集成 | 金属化塑料壳替代独立金属屏蔽罩 |

### 1.4 小天才的功耗真相

**小天才旗舰表实际续航仅1-2天。**

原因：Android系统 + 4G常在线 + 屏幕常亮 → 平均待机电流15-30mA → 600mAh电池只能撑1-2天。

> **小天才用续航换功能。他们选择了功能丰富，牺牲了待机时间。**

## 二、我们的产品需求 vs 现实约束

### 2.1 我们的需求

| 需求 | 说明 |
|------|------|
| 可视定位 | 摄像头 + 定位能力 |
| 能直播 | 实时视频推流 |
| 能定位 | GPS + WiFi辅助定位 |
| 续航久 | **待机超过10天** |
| 体积小 | 接近小天才手表大小 |

### 2.2 需求之间的矛盾

```
直播（视频）→ 大电流（300-800mA）→ 吃电池 → 需要大电池 → 体积大
    ↕
GPS持续开 → 耗电增加
    ↕
续航10天  → 需要极低待机功耗 → 功能受限
    ↕
体积小    → 电池容量受限 → 进一步压缩可用电量
```

**核心矛盾：小天才接受了1-2天续航，才换来了小体积+全功能。我们要求10天待机 + 直播 + 小体积，这三个目标在物理上互相冲突。**

## 三、为什么我们做不到跟小天才一样小

### 3.1 SoC集成度差距

|       | 小天才                  | 我们现状          |
| ----- | -------------------- | ------------- |
| SoC方案 | 穿戴级高集成SoC（展锐/MTK穿戴线） | 待定            |
| 芯片数量  | 1颗SoC + 内存 + 闪存      | 如用独立芯片方案需5-6颗 |
| PCB面积 | 极小（单SoC方案）           | 可能大3-4倍       |
| 定制能力  | ODM方案公司深度合作          | 我们缺乏同等资源      |

**定制SoC的成本门槛：**

| 路径            | 年用量要求 | 费用     | 周期      |
| ------------- | ----- | ------ | ------- |
| 让展锐/MTK定制SoC  | 500万+ | 数千万NRE | 12-18个月 |
| 自己设计SoC       | -     | 上亿     | 2-3年    |
| 定制SiP封装       | 50万+  | 数十万~百万 | 6-12个月  |
| 用现有SoC + 定制模组 | 几K    | 几十万    | 3-6个月   |

### 3.2 功耗目标的根本性差异

| | 小天才 | 我们的目标 |
|---|-------|----------|
| 待机续航 | 1-2天 | **10天+** |
| 系统架构 | 单SoC（Android常驻） | 必须双核架构 |
| 4G状态 | 常在线 | 不能常在线 |
| 待机电流 | 15-30mA | **需压到50μA以下** |

> **我们的10天待机要求，意味着不能使用小天才的单SoC方案。必须采用更复杂的双核架构，这反而会增加硬件复杂度和体积。**

## 四、可行技术路线

### 4.1 推荐方案：双核架构（待机核 + 性能核）

```
┌─────────────────────────────────────────┐
│              同一块PCB                   │
│                                         │
│  ┌────────────┐       ┌──────────────┐  │
│  │  低功耗MCU  │  SPI  │   穿戴SoC    │  │
│  │  （待机核） │←─────→│  （性能核）  │  │
│  │            │       │              │  │
│  │ 常供电     │       │ MOSFET控制   │  │
│  │ μA级功耗   │       │ 平时完全断电 │  │
│  └────────────┘       └──────────────┘  │
│                                         │
│  职责分配：                              │
│  MCU：WiFi扫描定位/BLE广播/传感器/唤醒   │
│  SoC：视频直播/拍照上传/Android运行      │
│                                         │
└─────────────────────────────────────────┘
```

### 4.2 功耗预算

**待机模式（SoC断电，仅MCU运行）：**

| 模块 | 平均电流 |
|------|---------|
| MCU深度休眠 | 2-5μA |
| BLE广播（1次/秒） | +5-10μA |
| WiFi扫描定位（5分钟1次） | +5μA |
| GNSS定位（30分钟1次） | +15μA |
| **合计** | **30-40μA** |

**续航计算：**
- 600mAh ÷ 0.04mA = **625天**（理论值）
- 考虑漏电、自放电等实际因素，按500μA估算：600mAh ÷ 0.5mA = **50天** ✅
- 每天唤醒直播5分钟：额外消耗约25mAh/天，10天250mAh
- 总消耗约260mAh，占600mAh的43% ✅

### 4.3 MCU选型（待机核）

| 方案 | 待机电流 | WiFi | BLE | 价格 | 推荐度 |
|------|---------|------|-----|------|--------|
| ASR3601 | 5-10μA | ✅集成 | ✅集成 | 低 | ⭐⭐⭐⭐⭐ |
| ESP32-C6 | 6-8μA | ✅集成 | ✅集成 | 极低 | ⭐⭐⭐⭐ |
| Nordic nRF5340 | 1.5μA | 需外挂 | ✅集成 | 中 | ⭐⭐⭐ |

**推荐ASR3601**：ASR是展锐子公司，与展锐穿戴SoC搭配有成熟双系统方案。

### 4.4 SoC选型（性能核）

| 方案 | 视频能力 | 特点 |
|------|---------|------|
| 展锐UMWPE-1 | H.264编码 | 穿戴成熟方案，与ASR MCU搭配 |
| MTK MT6739穿戴版 | H.264/H.265 | 性能好，方案商资源丰富 |
| 全志V85x | H.265编码 | 性价比高，视频能力强 |

### 4.5 行业验证

双核架构并非自创，**已是行业标准做法**：

| 产品 | 架构 |
|------|------|
| Apple Watch | 协处理器（W系列常开）+ 主SoC按需唤醒 |
| 华为Watch | LiteOS MCU + 鸿蒙主SoC |
| 小米手环 | 单MCU方案（30天续航，但无视频能力） |
| 小天才 | 类似双核，但4G常在线故续航短 |

## 五、结论与建议

### 5.1 核心结论

1. **小天才的小型化 = 高集成SoC + 妥协的续航**。他们接受了1-2天一充，才换来极致体积和全功能。
2. **我们的10天待机要求，决定了必须走双核架构**。这比小天才的方案更复杂，不是"做不到小天才那么小"，而是我们的需求比小天才更苛刻（10天 vs 1-2天）。
3. **不能定制SoC**。除非年用量500万+且有数千万NRE预算，否则只能选现有SoC。
4. **我们的差异化优势可以是续航**。小天才1-2天，我们能做10天+，这是卖点，不是劣势。

### 5.2 建议路线

```
阶段一（3-6个月）：
  选现有穿戴SoC + ASR3601 MCU
  标准模组方案，验证双核架构可行性
  体积目标：名片一半大小

阶段二（6-12个月）：
  找深圳方案公司深度定制PCB + 结构
  SiP封装（年用量50万+时启动）
  体积目标：挂件/胶囊大小

阶段三（12个月+）：
  量产后优化，考虑定制模组封装
  体积目标：逼近手表大小
```

## 六、外壳材质选型 — 轻量化分析

### 6.1 常用外壳塑料密度对比

| 材料 | 密度 g/cm³ | 相对ABS+PC | 特点 | 典型应用 |
|------|-----------|-----------|------|---------|
| **PP**（聚丙烯） | 0.90-0.91 | **轻18%** | 最轻的结构塑料 | 电池盖、轻量外壳 |
| **PE**（聚乙烯） | 0.92-0.97 | 轻10% | 太软，不推荐做外壳 | — |
| **TPE/TPV**（弹性体） | 0.90-1.10 | 轻5-15% | 软胶，适合缓冲层 | 表带、保护套 |
| **ABS**（纯） | 1.04-1.06 | 轻5% | 表面好、耐冲击差 | 低端外壳 |
| **PPE/PS**（Noryl） | 1.06-1.10 | 轻约3% | 耐热好、尺寸稳定 | 电池外壳、电子件 |
| **ABS+PC** | 1.10-1.15 | **基准** | 均衡之选 | 小天才、大部分穿戴 |
| **PC**（纯） | 1.20-1.22 | 重7% | 透明、耐冲击 | 镜片、透明壳 |
| **PA**（尼龙） | 1.13-1.15 | 持平 | 耐磨、耐油 | 运动手表外壳 |
| **PMMA**（亚克力） | 1.17-1.20 | 重5% | 透明、硬 | 镜片 |
| **POM**（赛钢） | 1.41-1.42 | 重25% | 超硬、耐磨 | 齿轮、按键 |
| **PPS** | 1.34-1.36 | 重20% | 耐高温、阻燃 | 连接器 |

### 6.2 ABS+PC是行业主流，但不是最轻

ABS+PC是"最安全的选择"，不是"最轻的选择"：

**优点：**
- 冲击强度高（不怕摔）
- 表面涂装/电镀/IMD工艺都成熟
- 注塑工艺成熟，良率高
- 尺寸稳定性好

**缺点：**
- 密度中等偏高（1.10-1.15 g/cm³）
- 比PP重约18%

### 6.3 更轻的替代方案

**方案A：PP + 玻纤增强（最轻，需要改性）**

```
密度：0.90 g/cm³ → 加GF15%后约0.95 g/cm³，仍比ABS+PC轻15%+

优点：最轻的结构塑料，成本低
缺点：
  - 纯PP刚性差，壁厚要加厚 → 抵消部分减重收益
  - 表面涂装困难（附着力差）
  - 不能直接喷涂漂亮颜色
  - 需要火焰处理/等离子处理才能涂装

适用场景：对表面质感要求不高的产品
```

**方案B：PC薄壁设计（壁厚优化收益更大）**

```
密度：1.20-1.22 g/cm³（比ABS+PC重7%）

但关键：PC流动性好，可注塑0.6-0.8mm超薄壁

同样外壳，不同壁厚对比：
  ABS+PC 壁厚1.2mm → 重量 X
  ABS+PC 壁厚1.0mm → 重量 0.83X（轻17%）
  PC     壁厚0.8mm → 重量 0.55X（轻45%）

结论：壁厚从1.2mm压到0.8mm，减重效果远超换材料
```

**方案C：PC + 嵌件注塑（薄壁+补强）**

```
PC壁厚0.8mm + 局部嵌0.15mm钢片补强
→ 兼顾超薄壁和结构强度
→ 比标准ABS+PC方案轻40-50%
→ 模具成本增加，但量产可行
```

### 6.4 更激进的轻量化方案

| 方案 | 重量 vs 标准ABS+PC | 成本 | 可行性 | 备注 |
|------|-------------------|------|--------|------|
| PP+GF改性 | 轻15-18% | 低 | ⭐⭐⭐⭐ | 表面处理是难点 |
| PC薄壁（0.8mm） | 轻30-45% | 中（模具贵） | ⭐⭐⭐ | 模具精度要求高 |
| PC+嵌件注塑（钢片补强） | 轻40-50% | 中高 | ⭐⭐⭐⭐ | 兼顾薄壁和强度 |
| PC+碳纤维增强 | 轻20-30% | 高 | ⭐⭐⭐ | 表面质感好 |
| 镁合金（薄壁压铸） | 轻30-40% | 高 | ⭐⭐⭐⭐ | 高端感，需防腐蚀 |
| 铝合金CNC+塑料内衬 | 轻20-30% | 高 | ⭐⭐⭐ | 外观好但CNC成本高 |
| 碳纤维复合材料 | 轻40-50% | 极高 | ⭐⭐ | 小批量不现实 |

### 6.5 对我们定位器的建议

```
推荐组合：

标准方案 → ABS+PC（壁厚1.0mm）
           均衡、安全、表面处理好、良率高

追求轻量 → PC薄壁（0.8mm）+ 局部嵌件补强
           壁厚减0.2mm，重量直接省15-20%

贴肤部分 → TPE软胶
           舒适、轻、贴合皮肤

避坑：
  × PP — 表面涂装痛苦，不适合做消费级外观
  × POM/PPS/LCP — 太重或场景不需要
  × 纯碳纤维 — 成本爆炸，小批量不现实
```

### 6.6 关键认知

> **换材料（ABS+PC → PP）最多省18%重量；优化壁厚（1.2mm → 0.8mm）能省40%+。轻量化的主战场在壁厚设计和结构优化，不在材料本身。**

---

> **一句话总结给领导：小天才用1-2天续航换了小体积和全功能。我们要10天续航，必须用更复杂的双芯片架构，体积会比小天才大一些，但续航是其5-10倍——这是产品定位差异，不是技术能力差距。外壳轻量化的关键不在换材料，在壁厚优化，从1.2mm压到0.8mm比从ABS+PC换PP减重效果大3倍。**

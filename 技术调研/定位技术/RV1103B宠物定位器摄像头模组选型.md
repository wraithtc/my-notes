## 摄像头模组参数拆解

### 1. 图像传感器 (Sensor)

传感器是模组的核心，决定画质、功耗和成本。

| 参数 | 作用 | 选型建议 |
|------|------|---------|
| **分辨率** | 决定图像清晰度 | 1080P (2MP) 足够，过高增加功耗和存储压力 |
| **像素尺寸** | 越大感光越好，夜视更强 | 2.8μm+ 较佳 |
| **光学尺寸** | 影响感光面积 | 1/3" ~ 1/2.9" 适合小型化 |
| **接口类型** | 与主控通信方式 | **MIPI CSI-2**（RV1103B支持） |
| **帧率** | 视频流畅度 | 30fps 足够 |
| **功耗** | 影响电池续航 | <100mW 运行功耗 |

### 2. 镜头 (Lens)

| 参数 | 作用 | 宠物定位器选型建议 |
|------|------|-------------------|
| **焦距** | 决定视场角和拍摄距离 | **2.7-3.6mm** 广角，捕捉周边环境 |
| **FOV视场角** | 可见范围宽度 | **100-120°** 广角，适合宠物视角 |
| **光圈 (F值)** | 进光量，越小越亮 | F1.8-F2.0，户外白天足够 |
| **镜头类型** | 固定焦/变焦/自动对焦 | **固定焦距 (FF)**，成本低、功耗低 |
| **IR Cut** | 红外滤光片 | **双滤光片切换** 或 **无IR**（白天场景可省） |
| **接口** | 镜头安装方式 | M12 或 内置模组镜头 |

### 3. 模组结构

| 参数 | 作用 | 建议 |
|------|------|------|
| **尺寸** | 安装空间 | ≤25×25mm 小型模组 |
| **高度** | 整机厚度控制 | ≤10mm 含镜头 |
| **连接器** | 与主板连接 | FPC排线 15-30pin |

### 推荐：GC2053

**选择理由：**
1. ✅ **RV1103B已验证兼容**（Luckfox开发板有驱动）
2. ✅ **价格适中**（模组¥25-35，符合预算）
3. ✅ **户外性能优秀**（高灵敏度、高信噪比）
4. ✅ **安防级设计**（专为IPC优化）
5. ✅ **低功耗**（适合电池供电）

## 镜头选型建议

### 焦距与视场角对照

| 焦距 | FOV | 适用场景 | 宠物定位器适配度 |
|------|-----|---------|-----------------|
| 1.8mm | 180°+ | 鱼眼全景 | ❌ 畸变太大 |
| **2.7mm** | **110-120°** | **超广角** | ✅ **推荐** |
| **3.6mm** | **90-100°** | **标准广角** | ✅ **推荐** |
| 6mm | 50-60° | 标准视角 | ❌ 视野太窄 |

### 推荐配置

| 参数 | 建议值 | 理由 |
|------|--------|------|
| **焦距** | 2.7mm 或 3.6mm | 广角捕捉宠物周边环境 |
| **FOV** | 100-120° | 足够视野，畸变可控 |
| **光圈** | F1.8-F2.0 | 户外白天足够 |
| **类型** | 固定焦距 | 无需对焦，低功耗 |
| **IR Cut** | 可选（白天场景可省） | 降低成本 |

## 功耗估算

| 状态 | 功耗 | 说明 |
|------|------|------|

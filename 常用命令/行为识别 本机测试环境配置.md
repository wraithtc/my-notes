# 1. 端口转发：Windows 8010 → WSL 172.20.166.1:8010
  netsh interface portproxy add v4tov4 listenport=8010 listenaddress=0.0.0.0 connectport=8010 connectaddress=172.20.166.1

  # 2. 防火墙放行
  netsh advfirewall firewall add rule name="WSL HomeMonitor 8010" dir=in action=allow protocol=TCP localport=8010

  然后手机浏览器打开：

  http://192.168.10.104:8010/h5/monitor?demo=golden_demo_2

  ▎ 注意：WSL IP 每次重启可能变化，访问不了时在 Windows PowerShell 运行 wsl hostname -I 获取新 IP，更新 portproxy 的 connectaddress

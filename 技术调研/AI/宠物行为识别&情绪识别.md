## 背景

1. 我提供平台+app+设备端到端服务
2. 宠物行为识别&情绪识别应用设备为家用摄像头，价格200-300左右
3. 场景为通过摄像头拍摄的宠物画面，判断宠物某一时间段在做什么，比如活跃/休息/睡觉/进食/排便等等
4. 刚开始我的用户不多，几百/几千，未来几年可能会到万级

**识别目标**: 猫和狗

**部署方式**: 全部服务端部署，设备端只负责采集和上传

### 2.3 推荐技术栈

#### 方案A: YOLO + 行为分类（推荐）

```
摄像头画面 → YOLO检测宠物 → 裁剪ROI → 行为分类模型 → 输出行为类别
```

**技术选型**:
- 检测: YOLOv8/YOLO12（120种犬类检测）
- 分类: ResNet / EfficientNet / Vision Transformer
- 时序: LSTM / Transformer（捕捉行为序列）

**优点**:
- YOLO实时性好，适合家用摄像头
- 成熟生态，部署简单
- 可基于开源数据集快速训练

---

#### 方案B: DeepLabCut + 行为分类

```
摄像头画面 → DeepLabCut姿态估计 → 骨架序列 → 行为分类 → 输出行为类别
```

**技术选型**:
- 姿态估计: DeepLabCut
- 行为分类: HMM / LSTM / 1D-CNN

**优点**:
- 姿态信息更丰富，行为识别更精准
- 对遮挡、光照变化更鲁棒
- 科研验证，精度高

**缺点**:
- 需要标注姿态数据
- 计算量较大

## 四、推荐方案

### 4.1 阶段一：MVP验证（当前阶段）

**推荐**: 商用API（宠智灵）

**理由**:
1. 快速上线验证产品价值
2. 无需投入大量研发资源
3. 技术风险低
4. 可专注产品体验和用户增长

**行动建议**:
1. 联系宠智灵获取API试用
2. 评估识别精度是否满足需求
3. 获取正式报价

---

### 4.2 阶段二：规模化（万级用户）

**推荐**: 自研 + 商用API混合

**策略**:
1. 核心行为识别自研（降低边际成本）
2. 复杂情绪识别调用API
3. 建立自有数据集，持续优化模型

**技术路线**:
1. 基于YOLOv8训练宠物检测+行为分类模型
2. 服务端GPU推理
3. 逐步积累数据，迭代模型

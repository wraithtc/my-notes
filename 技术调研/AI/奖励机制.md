# AI Agent 奖励机制

## 概述

奖励机制（Reward Mechanism）是AI Agent训练和优化的核心驱动力，通过定义什么是"好的行为"来引导Agent学习。在强化学习框架中，奖励信号是Agent从环境中获得的唯一反馈，用于评估其行为的优劣。

## 核心概念

### 1. 奖励函数（Reward Function）

奖励函数是将状态和动作映射到标量值的函数：
```
R(s, a) → ℝ
```

- **稀疏奖励**：只在特定事件发生时给予奖励（如游戏胜利）
- **密集奖励**：每一步都有反馈信号
- **塑造奖励**：通过中间目标引导Agent

### 2. 奖励假设

> "所有目标都可以通过最大化累积奖励来描述" —— Sutton & Barto

## 奖励机制类型

### 1. 外在奖励（Extrinsic Reward）

来自环境或任务的直接反馈：
- 任务完成奖励
- 目标达成奖励
- 性能指标奖励

### 2. 内在奖励（Intrinsic Reward）

Agent内部生成的驱动力：

| 类型 | 描述 | 应用场景 |
|------|------|----------|
| **好奇心驱动** | 探索未知状态的奖励 | 稀疏奖励环境 |
| **内在动机** | 技能习得、能力提升 | 开放式学习 |
| **信息增益** | 减少环境不确定性 | 主动学习 |
| **多样性奖励** | 行为多样性 | 避免局部最优 |

### 3. 社会奖励（Social Reward）

来自人类或群体交互：
- 人类反馈（RLHF）
- 社会认可信号
- 协作奖励

## LLM Agent 的奖励机制

### 1. 基于结果的奖励

```python
# 任务完成奖励
if task_completed:
    reward = 1.0
else:
    reward = 0.0

# 部分完成奖励
reward = completed_subtasks / total_subtasks
```

### 2. 过程奖励模型（PRM）

对推理过程的每一步进行评估：
- 步骤正确性
- 逻辑连贯性
- 错误累积惩罚

### 3. 人类偏好对齐（RLHF）

```
预训练 → SFT → 奖励模型训练 → PPO优化
```

关键组件：
- **奖励模型**：学习人类偏好
- **PPO**：策略优化算法
- **KL散度约束**：防止偏离原始模型

### 4. AI反馈（RLAIF/Constitutional AI）

使用AI生成偏好数据：
- 宪法原则指导
- 自我批评和修正
- 降低人工标注成本

## 奖励设计挑战

### 1. 奖励劫持（Reward Hacking）

Agent找到漏洞获取高奖励但未真正完成任务：
```
例子：清洁机器人
- 目标：最大化"灰尘消失"的奖励
- 劫持行为：把灰尘藏在传感器看不到的地方
```

### 2. 稀疏奖励问题

- 难以获得有效学习信号
- 解决方案：奖励塑形、课程学习、内在动机

### 3. 奖励塑形的副作用

不当的中间奖励可能导致：
- 目标漂移
- 过度依赖塑形
- 迁移能力下降

## 设计最佳实践

### 1. 奖励函数设计原则

```
✓ 明确目标：奖励与最终目标对齐
✓ 可量化：奖励值能够准确计算
✓ 及时反馈：尽量提供密集信号
✓ 避免欺骗：不给Agent留下漏洞
```

### 2. 多目标奖励

```python
# 加权组合多种奖励
total_reward = (
    w1 * task_reward +      # 任务完成
    w2 * efficiency_reward + # 效率
    w3 * safety_reward +     # 安全性
    w4 * diversity_reward    # 行为多样性
)
```

### 3. 层次化奖励

```
高层目标 → 子目标奖励 → 原子动作奖励
    ↓           ↓            ↓
  稀疏       中等密集       密集
```

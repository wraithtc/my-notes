# 君正T32 vs 瑞芯微RV1103B 对比

> 两者均为**AI视觉处理芯片**，非GPS定位芯片。主要面向智能摄像头、门锁、AIoT等应用场景。

## 核心参数对比

| 参数项 | 君正 T32 | 瑞芯微 RV1103B |
|--------|----------|----------------|
| **厂商** | 北京君正 (Ingenic) | 瑞芯微 (Rockchip) |
| **定位** | 智能视觉处理器 | 超低功耗AI图像处理器 |
| **CPU** | - | 单核 ARM Cortex-A7 @1.2GHz |
| **NPU算力** | **1.0 TOPS** (INT8) | **0.5 TOPS** (INT4/INT8/INT16) |
| **ISP** | Tiziano-v4.0 | 第三代ISP |
| **视频编码** | H.265 + H.264 | H.264/H.265 |
| **视频能力** | **8MP@25FPS** / 4K | **8MP@20FPS** / 4MP@30FPS |
| **内存** | SIP 512Mb/1Gb/2Gb DDR | 内置 64MB DDR2 |
| **多摄支持** | ✅ 支持 | 最多2个sensor |

---

## 🔋 功耗对比（重点）

| 功耗场景 | 君正 T32 | 瑞芯微 RV1103B |
|----------|----------|----------------|
| **AOV/待机模式** | **26mW** (含Sensor, 2M@1FPS) | **< 200µA** (配合片上PMU) |
| **典型运行功耗** | ~40mW+ | 低功耗设计（具体值待确认） |
| **能效比** | **0.07 mW/MHz** | 模块自动门控设计 |
| **优化技术** | AI编码智能降码率，待机功耗降低30% | 每模块自动门控，预录/全时录像优化 |

### 功耗分析

| 对比维度 | 说明 |
|---------|------|
| **T32优势** | AOV模式下26mW（含Sensor）表现优秀，AI算力更高但功耗控制良好 |
| **RV1103B优势** | 待机功耗极低（<200µA），适合电池供电的长期待机场景 |
| **能效比** | T32的0.07mW/MHz能效比在同等算力芯片中表现突出 |

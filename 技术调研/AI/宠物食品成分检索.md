## 一、可用的公开数据库与 API

### 1. Open Pet Food Facts（⭐ 首选推荐）

| 项目       | 说明                                      |
| -------- | --------------------------------------- |
| **网址**   | https://world.openpetfoodfacts.org      |
| **定位**   | 全球最大的开放宠物食品数据库（Open Food Facts 的姊妹项目）   |
| **数据量**  | 覆盖全球数十万款宠物食品产品                          |
| **数据内容** | 条形码、品牌、配料表、营养成分（蛋白质/脂肪/纤维/水分等）、添加剂、营养评级 |
| **API**  | REST API，支持按条形码查询、分类浏览、关键词搜索            |
| **数据格式** | JSON / CSV / RDF 数据全集可下载                |
| **许可**   | Open Database License (ODbL)，免费使用需署名    |

**常用 API 端点：**
```
# 按条形码查询
GET https://world.openpetfoodfacts.org/api/v0/product/{barcode}.json

# 按分类浏览
GET https://world.openpetfoodfacts.org/category/pet-food.json

# 关键词搜索
GET https://world.openpetfoodfacts.org/cgi/search.pl?search_terms=chicken&json=1
```

**优势：** 数据开放、有 API、支持全量数据下载、社区持续更新
**劣势：** 中国品牌覆盖可能不完整，配料翻译需要额外处理

---

### 2. USDA FoodData Central

| 项目       | 说明                            |
| -------- | ----------------------------- |
| **网址**   | https://fdc.nal.usda.gov/     |
| **定位**   | 美国农业部食品成分数据库                  |
| **数据内容** | 原料级别的详细营养成分（氨基酸、脂肪酸、矿物质、维生素等） |
| **API**  | REST API，需免费申请 API Key        |
| **用途**   | 查询单个原料（如鸡肉粉、鱼油、维生素E）的详细营养数据   |

**适用场景：** 当用户输入某个配料名时，用它查询该配料的精确营养成分
**注意：** 主要面向人类食品，但大多数宠物食品原料有重叠

---

### 3. openFDA Animal & Veterinary API

| 项目 | 说明 |
|------|------|
| **网址** | https://open.fda.gov/apis/animalandveterinary/ |
| **数据内容** | 宠物食品召回记录、不良事件报告 |
| **用途** | 查询某品牌/产品是否有安全召回历史 |

---

### 4. AAFCO / FEDIAF 标准文档

| 组织 | 网址 | 作用 |
|------|------|------|
| **AAFCO**（美国饲料管理协会） | https://www.aafco.org | 定义宠物食品营养标准和配料规范 |
| **FEDIAF**（欧洲宠物食品联合会） | https://europeanpetfood.org | 欧洲宠物食品营养指南 |

**用途：** 获取"猫/犬每日营养需求标准"，用于判断食品成分是否达标

---

### 5. 中国本土数据源

| 来源 | 说明 |
|------|------|
| **中国饲料工业协会** | 发布宠物饲料（食品）相关国家标准 |
| **农业农村部** | 宠物食品登记与监管信息（第 20 号公告等） |
| **GB/T 31216-2014** | 全价宠物食品 犬粮国家标准 |
| **GB/T 31217-2014** | 全价宠物食品 猫粮国家标准 |

**现状：** 目前中国尚无开放的宠物食品成分全量数据库 API，需要自行采集或爬取

### 核心模块设计

#### 模块 1：食品识别与数据获取
```
输入方式：
  - 条形码扫描 → 调用 Open Pet Food Facts API 获取产品数据
  - 品牌名搜索 → 关键词搜索 + 品牌匹配
  - 配料表文字 → OCR 识别 + NLP 解析配料列表
  - 拍照识别   → 图像识别配料表文字
```

#### 模块 2：配料解析引擎
```
功能：
  - 将配料表文本拆分为单个配料项
  - 配料标准化（"鸡胸肉" → "鸡肉"，"Chicken Breast" → "Chicken"）
  - 配料分类：
    · 主要蛋白质来源（鸡肉、牛肉、鱼肉...）
    · 碳水化合物来源（糙米、玉米、土豆...）
    · 脂肪来源（鸡脂、鱼油...）
    · 添加剂（防腐剂、抗氧化剂、着色剂...）
    · 维生素与矿物质
```

#### 模块 3：成分分析与评估（核心）
```
对每个配料项进行：
  1. 营养价值评估（基于 USDA FDC 数据）
  2. 对宠物（猫/犬）的益处分析
  3. 潜在风险与注意事项
  4. 常见过敏原标记
  5. AAFCO/FEDIAF 合规性检查
```

#### 模块 4：综合报告生成
```
输出：
  - 整体营养评级（A/B/C/D/F）
  - 各配料逐一分析
  - 优势亮点
  - 风险/争议配料高亮
  - 适用宠物类型（猫/犬/年龄段）
  - 改善建议
```

## 三、关键数据：宠物食品配料知识库

### 需要自建的知识库内容

> 这部分是公开 API 无法覆盖的，需要结合专业兽医资料构建

#### 猫犬常见有益配料

| 配料 | 对猫的好处 | 对犬的好处 |
|------|-----------|-----------|
| 鸡肉 | 优质动物蛋白，易消化 | 优质蛋白，低过敏风险 |
| 三文鱼 | Omega-3，美毛护肤 | Omega-3，抗炎关节保护 |
| 鸡脂 | 提供必需脂肪酸 | 高能量密度 |
| 蓝莓 | 抗氧化 | 抗氧化，泌尿健康 |
| 南瓜 | 纤维，助消化 | 纤维，腹泻/便秘调节 |
| 鱼油 | EPA/DHA，皮肤毛发健康 | 关节、心血管健康 |

#### 猫犬常见争议/有害配料

| 配料 | 风险等级 | 说明 |
|------|---------|------|
| BHA/BHT | ⚠️ 中高 | 化学防腐剂，潜在致癌风险 |
| 乙氧基喹啉 | ⚠️ 高 | 合成抗氧化剂，多国已禁用 |

| 葡萄/葡萄干 | 🚫 高 | 对犬可致急性肾衰竭 |

## 四、技术实现建议

### 方案 A：LLM + 规则引擎混合（推荐）

```
架构：
  ┌─ 规则引擎：处理标准化判断（AAFCO标准对比、过敏原匹配、毒性配料标记）
  └─ LLM：处理自然语言解释、个性化建议生成

优点：
  - 准确性高（规则引擎兜底关键安全判断）
  - 灵活（LLM 生成用户友好的解释）
  - 成本可控（规则引擎处理 70% 逻辑，LLM 处理 30%）

技术栈建议：
  - 后端：Node.js / Python (FastAPI)
  - 数据源：Open Pet Food Facts API + 自建配料知识库
  - LLM：Claude API / GPT-4
  - 数据库：PostgreSQL（产品数据） + 向量数据库（配料知识检索）
```

### 方案 B：纯 LLM 方案（快速启动）

```
架构：将配料知识作为 System Prompt / RAG 上下文，直接用 LLM 分析

优点：开发快，初始成本低
缺点：纯 LLM 可能产生幻觉，对安全性判断不够可靠
适用：MVP 阶段、小规模验证
```

### 方案 C：纯规则引擎（安全优先）

```
架构：基于预设规则和数据库查询，无 LLM

优点：结果 100% 确定性，安全
缺点：用户体验差（无自然语言解释），维护成本高（规则需持续更新）
适用：仅做成分查询 + 安全警示的简单工具
```

## 六、结论

**有没有全量数据库？** 
- ✅ **Open Pet Food Facts** 是最接近"全量"的免费开放宠物食品数据库，有 API，推荐作为主数据源
- ⚠️ 但没有任何一个数据库能覆盖全球所有产品，特别是中国本土品牌覆盖较弱
- 建议：**Open Pet Food Facts 为主 + 自建知识库为辅 + LLM 做智能分析**

**推荐实现路径：**
> **方案 A（LLM + 规则引擎）** 最为可靠，用规则引擎确保安全关键判断的准确性，用 LLM 提供友好的分析报告和个性化建议

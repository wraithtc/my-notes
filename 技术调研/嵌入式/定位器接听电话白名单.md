# 定位器 VoLTE 来电白名单技术实现分析

## 一、问题背景

智能宠物定位器具备双向 VoLTE 通话能力，设备设置为**自动接听**模式（宠物无法操作接听键）。
这带来一个严重安全隐患：**任何人拨打电话都能接通，设备可被当作远程监听器使用**。

核心需求：
- 仅允许白名单号码来电接通
- 白名单之外的来电自动拒接（静默挂断）
- 白名单由主人通过 APP 远程管理
- 防止设备被滥用为监听工具

> **参考对象**：小天才电话手表（imoo）——儿童智能手表领域的标杆产品，同样面临"防止陌生人联系儿童"的需求，其白名单机制经过大规模验证。

## 二、小天才电话手表的白名单模式分析

### 2.1 小天才的通话管控策略

| 策略 | 说明 |
|------|------|
| **仅通讯录来电** | 只有家长在 APP 中添加的联系人才能拨通手表 |
| **陌生人拦截** | 非通讯录号码来电 → 静默挂断，手表无任何提示 |
| **短信过滤** | 同样只接收通讯录号码的短信 |
| **紧急号码放行** | 110/119/120 等紧急号码不受白名单限制 |
| **通话时长限制** | 可设置单次通话最长时间，防止长时间监听 |
| **通话时段限制** | 可设置允许来电的时段（如上课期间禁止来电） |

### 3.2 白名单数据结构设计

```c
#include <stdint.h>
#include <stdbool.h>

// 白名单条目
typedef struct {
    char phone_number[20];     // 归一化号码（去+86，纯数字）
    char contact_name[32];     // 联系人备注
    uint8_t  priority;         // 优先级：0=普通，1=高（主人）
    uint8_t  enabled;          // 是否启用：1=启用，0=禁用
    uint32_t sync_timestamp;   // 最后同步时间（防回滚）
} whitelist_entry_t;

// 白名单管理器
#define MAX_WHITELIST_SIZE  50   // 宠物定位器通常联系人较少

typedef struct {
    whitelist_entry_t entries[MAX_WHITELIST_SIZE];
    uint16_t count;
    uint32_t version;            // 白名单版本号（递增）
    uint8_t  checksum[32];       // HMAC-SHA256 校验
} whitelist_manager_t;

// 全局实例
static whitelist_manager_t g_whitelist;
```

### 3.3 号码归一化处理

> **关键**：运营商可能以上不同格式上报来电号码（`+86138xxxx`、`138xxxx`、`86138xxxx`），
> 必须归一化后才能正确匹配。

```c
// 号码归一化：去除 +86 / 86 前缀，保留纯数字
void phone_number_normalize(const char *raw, char *normalized, size_t buf_size) {
    size_t j = 0;
    for (size_t i = 0; raw[i] && j < buf_size - 1; i++) {
        if (raw[i] >= '0' && raw[i] <= '9') {
            normalized[j++] = raw[i];
        }
    }
    normalized[j] = '\0';

    // 去除 86 前缀（中国号码）
    if (j == 13 && normalized[0] == '8' && normalized[1] == '6') {
        memmove(normalized, normalized + 2, 11);
        normalized[11] = '\0';
    }
}
```

### 3.4 白名单匹配引擎

```c
// 精确匹配 + 后缀匹配（兼容短号等情况）
bool whitelist_match(const char *caller_number) {
    char normalized[20];
    phone_number_normalize(caller_number, normalized, sizeof(normalized));

    // 1. 紧急号码强制放行
    if (is_emergency_number(normalized)) {
        return true;
    }

    // 2. 遍历白名单匹配
    for (int i = 0; i < g_whitelist.count; i++) {
        if (!g_whitelist.entries[i].enabled) continue;

        char entry_normalized[20];
        phone_number_normalize(g_whitelist.entries[i].phone_number,
                               entry_normalized, sizeof(entry_normalized));

        // 精确匹配
        if (strcmp(normalized, entry_normalized) == 0) {
            return true;
        }

        // 后7位匹配（兼容号码格式差异）
        size_t len_caller = strlen(normalized);
        size_t len_entry  = strlen(entry_normalized);
        if (len_caller >= 7 && len_entry >= 7) {
            if (strcmp(normalized + len_caller - 7,
                       entry_normalized + len_entry - 7) == 0) {
                return true;
            }
        }
    }

    return false;
}

// 紧急号码判断
bool is_emergency_number(const char *number) {
    return (strcmp(number, "110") == 0 ||
            strcmp(number, "119") == 0 ||
            strcmp(number, "120") == 0 ||
            strcmp(number, "122") == 0);
}
```

### 3.5 来电拦截核心流程

```c
// Modem URC 回调 — 来电事件处理
void on_urc_ring(const char *urc_data) {
    // 等待 CLIP（来电号码）信息，通常在 RING 后几毫秒到达
    // 设置超时定时器：如果 500ms 内未收到 CLIP，则主动查询
    start_clip_timeout_timer(500);
}

void on_urc_clip(const char *caller_id) {
    cancel_clip_timeout_timer();

    if (whitelist_match(caller_id)) {
        // ✅ 白名单内 → 自动接听
        call_log_record(CALL_ACCEPTED, caller_id);
        // 延迟 2 秒后自动接听（模拟振铃感）
        start_auto_answer_timer(2000);
    } else {
        // ❌ 非白名单 → 静默拒接
        call_log_record(CALL_REJECTED, caller_id);

        // 立即挂断，设备无任何声光提示
        modem_send_cmd("ATH\r\n");

        // 可选：上报云端通知主人
        cloud_report_event(EVENT_CALL_BLOCKED, caller_id);
    }
}

// CLIP 超时处理（未收到来电号码）
void on_clip_timeout(void) {
    // 无法获取来电号码 → 保守策略：拒接
    modem_send_cmd("ATH\r\n");
    call_log_record(CALL_REJECTED_NO_CLIP, "unknown");
}

// 自动接听执行
void on_auto_answer_timer(void) {
    modem_send_cmd("ATA\r\n");  // 接听来电

    // 可选：启动通话时长限制定时器
    #ifdef MAX_CALL_DURATION_SEC
    start_max_duration_timer(MAX_CALL_DURATION_SEC);
    #endif
}

// 通话时长限制
void on_max_duration_timer(void) {
    modem_send_cmd("ATH\r\n");  // 超时强制挂断
    call_log_record(CALL_DURATION_LIMIT, "");
}
```

### 3.6 Modem AT 指令交互序列

```
                    定位器                          运营商网络
                      │                                │
                      │   ← URC: RING                  │
                      │   ← URC: +CLIP: "138xxxx",129  │  来电号码上报
                      │                                │
              [白名单匹配 "138xxxx"]                     │
                      │                                │
               匹配成功 │──── AT+ATA ────►│  自动接听
                      │                                │
               匹配失败 │──── ATH ────────►│  静默挂断
                      │                                │
```

**关键 AT 指令**：

| AT 指令 | 功能 | 说明 |
|---------|------|------|
| `AT+CLIP=1` | 启用来电号码显示 | 必须初始化时开启 |
| `AT+COLP=1` | 启用被叫号码显示 | 可选 |
| `ATA` | 接听来电 | 白名单匹配成功时发送 |
| `ATH` | 挂断来电 | 白名单匹配失败时发送 |
| `AT+VTS` | 发送 DTMF 音 | 可选，用于 IVR 交互 |
| `AT+CLCC` | 查询当前通话状态 | 通话管理 |

### 3.7 通话时长与时段控制

```c
// 通话策略配置（云端下发）
typedef struct {
    bool     auto_answer_enabled;       // 是否自动接听
    uint16_t auto_answer_delay_ms;      // 自动接听延迟（毫秒）
    uint16_t max_call_duration_sec;     // 单次通话最大时长（秒）
    uint8_t  allowed_hours_start;       // 允许来电时段 开始（小时）
    uint8_t  allowed_hours_end;         // 允许来电时段 结束（小时）
    bool     reject_all_mode;           // 全拒模式（紧急情况一键屏蔽）
} call_policy_t;

static call_policy_t g_call_policy = {
    .auto_answer_enabled    = true,
    .auto_answer_delay_ms   = 2000,
    .max_call_duration_sec  = 180,    // 默认最长 3 分钟
    .allowed_hours_start    = 7,      // 早 7 点
    .allowed_hours_end      = 22,     // 晚 10 点
    .reject_all_mode        = false,
};

// 时段检查
bool is_within_allowed_hours(void) {
    if (g_call_policy.reject_all_mode) return false;

    uint8_t current_hour = rtc_get_hour();
    if (g_call_policy.allowed_hours_start <= g_call_policy.allowed_hours_end) {
        return (current_hour >= g_call_policy.allowed_hours_start &&
                current_hour <  g_call_policy.allowed_hours_end);
    } else {
        // 跨午夜的情况（如 22:00 - 07:00）
        return (current_hour >= g_call_policy.allowed_hours_start ||
                current_hour <  g_call_policy.allowed_hours_end);
    }
}
```

### 4.3 设备端同步处理

```c
// 收到云端白名单推送
void on_cloud_whitelist_sync(const uint8_t *payload, size_t len) {
    // 1. 解析 JSON
    cJSON *root = cJSON_ParseWithLength(payload, len);
    if (!root) return;

    // 2. 验证签名
    if (!verify_hmac_sha256(root, device_secret_key)) {
        LOG_W("Whitelist sync: signature verification failed!");
        cJSON_Delete(root);
        return;
    }

    // 3. 版本检查（防回滚）
    uint32_t new_version = cJSON_GetObjectItem(root, "version")->valueint;
    if (new_version <= g_whitelist.version) {
        LOG_I("Whitelist sync: ignored stale version %d (current %d)",
              new_version, g_whitelist.version);
        cJSON_Delete(root);
        return;
    }

    // 4. 解析并更新白名单
    parse_and_update_whitelist(root);

    // 5. 持久化到 Flash（加密存储）
    whitelist_save_to_flash();

    // 6. 发送 ACK
    cloud_send_ack(CMD_WHITELIST_SYNC, new_version, ACK_OK);

    cJSON_Delete(root);
    LOG_I("Whitelist updated to version %d, %d entries", 
          new_version, g_whitelist.count);
}
```

## 五、安全性深度分析

### 5.1 威胁模型

| 威胁 | 风险等级 | 对策 |
|------|----------|------|
| **任意号码拨打监听** | 🔴 高 | 白名单拦截（核心方案） |
| **号码伪造（Caller ID Spoofing）** | 🟡 中 | VoLTE IMS 域验证 + 短时多次拒接告警 |
| **白名单数据被篡改** | 🟡 中 | Flash 加密 + HMAC 签名校验 |
| **中间人攻击云端通信** | 🟡 中 | TLS 1.3 + 证书双向认证 |
| **暴力呼叫骚扰** | 🟠 中 | 频率限制 + 静默模式 |
| **SIM 卡被取出插入其他设备** | 🟡 中 | 设备锁卡（SIM Lock）+ 首次绑定 |

### 5.2 防号码伪造

VoLTE 环境下，来电号码通过 **IMS (IP Multimedia Subsystem)** 网络传递。
运营商 IMS 核心网通常会对主叫号码进行验证，但跨运营商场景可能存在号码伪造风险。

**增强方案**：
```c
// 异常来电检测
typedef struct {
    char     number[20];
    uint32_t first_seen_time;
    uint16_t reject_count;
    uint16_t reject_count_today;
} blocked_caller_t;

#define MAX_BLOCKED_LOG  20
static blocked_caller_t g_blocked_callers[MAX_BLOCKED_LOG];

// 记录并检测异常来电模式
void on_call_rejected(const char *number) {
    blocked_caller_t *entry = find_or_create_blocked(number);

    entry->reject_count++;
    entry->reject_count_today++;

    // 同一号码短时间内多次拨打 → 上告警告
    if (entry->reject_count_today >= 3) {
        cloud_report_alert(ALERT_SUSPICIOUS_CALL, number,
                          entry->reject_count_today);
    }

    // 更严格的模式：5次以上 → 加入临时黑名单，24h内直接丢弃RING
    if (entry->reject_count_today >= 5) {
        add_temp_blacklist(number, 24 * 3600);  // 24小时
    }
}
```

### 5.3 Flash 加密存储

```c
// 白名单写入 Flash 前加密
int whitelist_save_to_flash(void) {
    uint8_t plaintext[sizeof(whitelist_manager_t)];
    uint8_t ciphertext[sizeof(whitelist_manager_t) + 16];  // AES padding

    memcpy(plaintext, &g_whitelist, sizeof(g_whitelist));

    // AES-256-CBC 加密
    size_t cipher_len = aes256_cbc_encrypt(
        device_encryption_key,    // 设备唯一密钥（安全引导时派生）
        device_iv,
        plaintext, sizeof(plaintext),
        ciphertext
    );

    // 写入 NVS Flash
    return nvs_write_block(NVS_PARTITION_WHITELIST,
                           NVS_KEY_WHITELIST,
                           ciphertext, cipher_len);
}
```

## 七、对比：不同平台实现路径

| 维度 | RTOS 方案（定位器） | Android 方案（手表） |
|------|---------------------|---------------------|
| **平台** | ASR1602 / Unisoc 8910DM | Snapdragon Wear / MT6739 |
| **系统** | FreeRTOS / RT-Thread | Android 8.1+ / Wear OS |
| **来电拦截** | AT 指令 (CLIP + ATH/ATA) | `InCallService` / `CallScreeningService` |
| **白名单存储** | Flash NVS (加密) | SQLite + Android Keystore |
| **云端通信** | MQTT / CoAP（轻量） | MQTT / HTTP Long Poll |
| **号码匹配** | 自实现（C） | 系统联系人 API |
| **功耗** | 极低（< 5mA 待机） | 较高（需优化 Doze） |
| **成本** | ￥20-40 芯片级 | ￥80-150 方案级 |
| **适用场景** | ✅ 宠物定位器、资产追踪 | ✅ 儿童手表、老人手环 |

### Android（手表/平板）方案参考

```java
// Android 来电拦截 — 利用 CallScreeningService (Android 9+)
public class WhitelistCallScreeningService extends CallScreeningService {
    @Override
    public void onScreenCall(Call.Details details) {
        String number = details.getHandle().getSchemeSpecificPart();

        if (WhitelistManager.getInstance().isInWhitelist(number) ||
            isEmergencyNumber(number)) {
            // 允许来电 → 放行后由 InCallService 自动接听
            respondToCall(details.getCall(), 
                         new CallResponse.Builder()
                             .setShouldAllowCall(true)
                             .build());
        } else {
            // 拦截来电 → 静默拒接，不响铃不通知
            respondToCall(details.getCall(),
                         new CallResponse.Builder()
                             .setShouldRejectCall(true)
                             .setShouldSilenceCall(true)
                             .build());

            // 记录并上报
            CloudReporter.reportBlockedCall(number);
        }
    }
}
```

> **注意**：Android 的 `CallScreeningService` 需设为默认拨号应用（Dialer）才能生效，
> 嵌入式 Android 设备（手表）通常直接定制系统框架，无此限制。
